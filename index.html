About the Project

Our project is a secure messenger web application that supports real-time public chat and private one-to-one messaging. The goal is to create a simple communication platform where users can log in, view connected users, and send messages easily. We plan to introduce features such as the ability to view which users are online, typing indicators, and read receipts.
